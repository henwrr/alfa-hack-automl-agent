## Дополнение: сравнение семейств и два worker

Runtime-коммит `9b7a748`, полный suite: **160 passed, 1 ConvergenceWarning, 44.43s**, exit 0. Предупреждение относится к маленькому synthetic fixture Linear, не к провалу теста. Проверены реальный batch двух ML-процессов, независимые ошибки, динамический deadline, отмена потомков, закрытие генератора, стабильный tie-break, восстановление неизвестных исходов без повторения и reserve policy. Независимое [ревью](tasks/parallel-research/REVIEW.md) не нашло P1/P2.

Новые полные public-прогоны используют Ollama qwen3.5:9b, бюджет 1200 секунд на задачу, trial timeout 180 секунд, seed 42, holdout 20%, `--parallel-trials 2 --n-jobs 4 --family-trials 3`. Общие trial-лимиты: 7 для регрессии и 11 для классификации. Они выполнялись последовательно. Все оценки ниже относятся к фиксированному holdout; скрытые test labels недоступны.

Регрессия улучшилась относительно прежнего CatBoost baseline благодаря начальному сравнению семейств. Четыре generated-кандидата регрессии завершились ошибками, поэтому статус честно `degraded`; финальное обучение ExtraTrees успешно. `completed` у классификации означает наличие успешно выполненного generated trial и не гарантирует улучшения или правильности всех утверждений LLM.

Проверка фактического кода классификации выявила неподтверждённую гипотезу о весах: trial_0006 вычисляет sample_weight, но не передаёт его в fit; y_train также отсутствует в model context. Этот опыт не доказывает эффект весов. Его метрика совпала с trial_0005; оба отклонены. Host гарантирует независимое измерение, а семантическую корректность произвольной гипотезы автоматически не доказывает.

Скрипт [verify_public_artifacts.py](tasks/parallel-research/verify_public_artifacts.py) заново пересчитал метрики всех успешных trials, проверил схему CSV и порядок ID, загрузил обе финальные модели и сверил predict с CSV. По реальным subprocess-интервалам подтверждены пересечения процессов, максимум два активных worker и восемь объявленных CPU-потоков; каждый worker настроен на четыре потока. Финальный refit не пересекался с исследовательскими worker. Это интервалы процессов, не только model.fit, и не доказательство жёсткой OS-изоляции CPU.

После удаления decisions.jsonl и повреждения agent.log `--resume` восстановил обе проекции точно; canonical events и их SHA256 не изменились, новых LLM-вызовов или обучения не было. Reserve воспроизведён из measured winner, фактического размера fit split и коэффициента 1.5; final timeout взят из оставшегося общего бюджета, без отдельного ограничения trial timeout.

## Границы проверки

- API организаторов отсутствует: адрес, модель, тариф и конкретное поведение tools не проверены. Подключение — через baseline env.
- Docker CLI отсутствует: Dockerfile подготовлен, образ здесь не собирался. Сам Python runtime и архив проверены непосредственно.
- Поддерживаются supervised tabular CSV и вывод целевого значения/метки класса. Probability/multicolumn submissions и неизвестные private-форматы требуют расширения контрактов.
- AST lint, env scrubbing и supervisor не являются OS security sandbox. Жёсткая изоляция файлов/сети и лимиты контейнера должны обеспечиваться внешним окружением.
- Полный трёхчасовой soak не проводился: реальные прогоны завершились раньше; остановки и сбои проверены целевыми тестами. Денежный бюджет нельзя точно перевести в токены до появления тарифа API.
