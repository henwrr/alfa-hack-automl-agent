Это собственная holdout-валидация (seed 42, 20%), а не score платформы. В public-прогонах лучший результат дал встроенный baseline harness; ухудшающие LLM-кандидаты отклонены. В классификации два LLM-скрипта завершились исключениями, следующая гипотеза была исправлена и выполнена. Успешный эксперимент не означает улучшения метрики.

Оба public-прогона использовали полный предоставленный train/test, единый CLI и неизменные правила discovery/evaluator. После них усилены recovery и token admission; итоговая версия дополнительно проверена на новой схеме через живую Ollama. Код кандидатов, окружение и логи находятся локально в runs/ollama-public/ и runs/ollama-current/; объёмные артефакты не включаются в Git/ZIP.

Итоговые CSV повторно прошли независимый validator: колонки, количество и порядок ID, конечные числа/допустимые классы. Все три модели загружены из model.joblib отдельно от worker; повторный predict на первых test-строках совпал с CSV.

## Границы проверки

- API организаторов отсутствует: адрес, модель, тариф и конкретное поведение tools не проверены. Подключение — через baseline env.
- Docker CLI отсутствует: Dockerfile подготовлен, образ здесь не собирался. Сам Python runtime и архив проверены непосредственно.
- Поддерживаются supervised tabular CSV и вывод целевого значения/метки класса. Probability/multicolumn submissions и неизвестные private-форматы требуют расширения контрактов.
- AST lint, env scrubbing и supervisor не являются OS security sandbox. Жёсткая изоляция файлов/сети и лимиты контейнера должны обеспечиваться внешним окружением.
- Полный трёхчасовой soak не проводился: реальные прогоны завершились раньше; остановки и сбои проверены целевыми тестами. Денежный бюджет нельзя точно перевести в токены до появления тарифа API.
