## Границы проверки

- API организаторов отсутствует: адрес, модель, тариф и конкретное поведение tools не проверены. Подключение — через baseline env.
- Docker CLI отсутствует: Dockerfile подготовлен, образ здесь не собирался. Сам Python runtime и архив проверены непосредственно.
- Поддерживаются supervised tabular CSV и вывод целевого значения/метки класса. Probability/multicolumn submissions и неизвестные private-форматы требуют расширения контрактов.
- AST lint, env scrubbing и supervisor не являются OS security sandbox. Жёсткая изоляция файлов/сети и лимиты контейнера должны обеспечиваться внешним окружением.
- Полный трёхчасовой soak не проводился: реальные прогоны завершились раньше; остановки и сбои проверены целевыми тестами. Денежный бюджет нельзя точно перевести в токены до появления тарифа API.

## MVP с CV и диагностикой, 21 октября 2026

Проверка через реальную Ollama qwen3.5:9b на полных публичных данных. Значения CLI по умолчанию теперь используют общий бюджет до10800s без фиксированного числа trials/steps; для этой проверки установлен общий бюджет3600s на задачу. Завершение текущего исследования и итоговое обучение выполнены через `--resume --finalize-only` по просьбе пользователя зафиксировать промежуточный MVP. Новых LLM-вызовов и повторного CV при этом нет.

| Проверка | Регрессия | Классификация |
|---|---:|---:|
| Train / test rows | 53 308 / 22 449 | 87 670 / 41 166 |
| Схема | 4 forward-group folds | 5 stratified folds |
| OOF coverage | 0.9602874 | 1.0 |
| Лучший стартовый кандидат | ExtraTrees: RMSE48.63484 | XGBoost: Macro F1 0.6110302 |
| Лучший LLM-кандидат | ExtraTrees: RMSE48.55996 | XGBoost: Macro F1 0.6123388 |
| Успешных LLM trials | 10 | 4 |
| Мета-оценка постобработки | RMSE48.23387 | Macro F1 0.6475200 |
| База на той же части мета-оценки | RMSE48.83698 | Macro F1 0.6123388 |
| Calibration OOF score | RMSE47.88738 | Macro F1 0.6466877 |

Регрессия: в train обнаружены Year_Factor1–5, в test6. Каждый внешний fold обучается только на прошлых периодах, earliest period не получает OOF. Мета-оценка использует только более поздние folds после первой калибровочной группы; поэтому её baseline48.83698 сравним с assessed48.23387, а не с best single48.55996 на всех OOF строках. Adversarial ROC-AUC=1.0, в том числе после исключения временного столбца: остаётся выраженный train/test сдвиг. Бленд ET/CatBoost/LightGBM имеет веса0.5/0.25/0.25.

Классификация: adversarial ROC-AUC=0.73345. CatBoost не завершил полный CV за trial timeout1800s и не получил score; это ограничение локального времени, а не доказательство худшего качества семейства. LightGBM0.5776474, ExtraTrees0.4852362, XGBoost0.6110302 завершены. LLM улучшила colsample_bytree XGBoost до0.7, score0.6123388. Фактически применённые balanced weights повысили F1 DoS/Worms, но ухудшили другие классы и общую Macro F1 до0.603841; успешное применение весов само по себе не гарантирует прироста. Финальный бленд XGBoost/LightGBM0.75/0.25 с множителями классов проверен cross-fitted методом. Два trial, прерванных при обновлении harness и ручном завершении исследования, отмечены interrupted и не повторяются автоматически.

Мета-оценки используют адаптивно выбранные базовые OOF модели. Это не nested CV и не независимый test score. Calibration OOF score отдельно показывает подбор на всех доступных OOF. Скрытые test labels не использованы и недоступны; локальные метрики нельзя отождествлять с результатом платформы.

Старый regression run сохранил все14 успешных trials, но пропустил final refit из-за квадратичного перечисления непрерывных targets как классов при постобработке:447.152s. Причина исправлена; тот же мета-поиск занимает0.213s в прямом replay и выполняется в ограниченном subprocess, сохраняя резерв refit. Для завершения этого run общий бюджет увеличен с2700s до3600s; исходные события не удалялись. Все сохранённые CV результаты повторно проверяются host evaluator.
