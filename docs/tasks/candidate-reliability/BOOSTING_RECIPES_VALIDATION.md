# Проверка boosting recipes

Добавлены LightGBM и XGBoost recipes с native CPU estimators и preprocessing из проверенного ExtraTrees template. Сгенерированный source проходит AST lint и не импортирует `automl_agent`; optional libraries импортируются только самим generated model code. XGBoost classification builder ожидает encoded `y`; отдельный training helper оборачивает модель и возвращает исходные labels.

`normalize_recipe` валидирует новые native параметры и host-side `fit_options`: `early_stopping_rounds` 0–300, `inner_validation_fraction` 0.1–0.3 и `sample_weight` None/`balanced`/`sqrt_balanced`. Запрещены sample weights вместе с estimator class weights и ранняя остановка на неподдерживаемых семействах. Fit options входят в canonical fingerprint; legacy recipes с опущенными опциями сохраняют прежний JSON shape, а fingerprint использует их defaults. CatBoost legacy default по-прежнему 150 итераций. Strong research recipes: CatBoost 3000/.05/depth 6, LightGBM 5000/.05/31 leaves, ExtraTrees 180/128 и XGBoost 3000/.05/depth 6; для boost-вариантов включена host-controlled early stopping на 100 round.

Включены tiny fit/predict для обеих задач у LightGBM/XGBoost, encoded target для XGBoost, смешанные numeric/category данные, NaN/inf, неизвестные категории, optional-package availability, fit-options и fingerprint, AST lint, joblib save/load и отсутствие eager imports при загрузке `automl_agent.recipes`. Также прошли прежние recipe/family/agent tests. Два SAGA ConvergenceWarning относятся к существующим крошечным Linear classification fixtures.
