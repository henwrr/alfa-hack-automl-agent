# Проверка model recipes

Добавлен декларативный API `default_recipe`, `normalize_recipe`, `recipe_code`, `recipe_fingerprint` и `recipe_catalog` для CatBoost, ExtraTrees и Linear. Нормализатор проверяет семейство, тип задачи, ключи, типы и границы; отдельно отклоняет `class_weights`, `sample_weight`, неподдержанный early stopping и host-controlled параметры. Generated source строится на проверенных шаблонах `families._source`, остаётся self-contained и применяет только нормализованные estimator parameters. Для ExtraTrees и Linear доступен numeric missing indicator через `SimpleImputer.add_indicator`.

Проверка: `/Users/egoraprelsky/Desktop/coding/alfa_hackathon/.venv/bin/python -m pytest tests/test_recipes.py tests/test_families.py -q` — **62 passed**. Она включает candidate AST lint, небольшие fit/predict для обоих task types, строковые метки, числовые и категориальные `NaN`/`inf`, class weights, CatBoost native categories и явные CatBoost overrides, joblib round trips и выполнение generated Linear recipes через worker manifest с сохранением/загрузкой модели. Два `ConvergenceWarning` возникают у SAGA на маленьких искусственных наборах; проверки прошли.

Linear classification recipe сохраняет базовые `C=0.5`, `max_iter=300`, `solver="saga"` и `class_weight=None`. Для CatBoost начальные dynamic defaults `depth`, `learning_rate`, `l2_leaf_reg` и `border_count` не переопределяются. Recipe хранит `auto_class_weights=None` для canonical fingerprint, а generated code опускает это значение: установленная версия CatBoost завершает fit ошибкой при передаче явного `None` для этого параметра. Native-значение CatBoost `"None"` теперь нормализуется в Python `None` и имеет тот же fingerprint, что omission/default. Весящее значение `"Balanced"` прошло tiny fit.

Если recipe просит numeric missing indicators, а context содержит только категориальные признаки, standalone builder теперь сообщает `ValueError` с понятным требованием numeric feature до `set_params`.

До первой реализации тестовый модуль был добавлен и запущен; collection остановился с ожидаемым `ImportError`, поскольку `automl_agent.recipes` ещё не существовал. Follow-up тесты сначала дали три ожидаемых отказа: alias `"None"` не нормализовался, `sample_weight` не упоминал CatBoost weights, а indicator без numeric branch показывал сырой `ColumnTransformer` error. После исправлений целевой набор и прежние family tests прошли. Публичные датасеты, Ollama и полный проектный suite в этом worktree не запускались; baseline MacroF1/RMSE на публичных данных здесь не измерялся.
