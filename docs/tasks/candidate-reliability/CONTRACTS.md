# Контракты

## recipes (исполнитель, собственные файлы automl_agent/recipes.py и tests/test_recipes.py)
Не менять families.py/agent.py/contracts.py. Использовать проверенные templates families._source. `default_recipe(family,task_type) -> dict` нормализованный JSON {family,parameters,preprocessing}; `normalize_recipe(recipe, task_type) -> dict` строгая валидация ключей/типов/предела; `recipe_code(recipe,task_type,n_jobs=4) -> str` полное self-contained build_model, preprocessing сохранён; `recipe_fingerprint(recipe,task_type) -> str` canonical normalized JSON hash; `recipe_catalog(task_type) -> dict` описания допустимых params/options для LLM. Family CatBoost/ExtraTrees/Linear.

Параметры содержат полные явные defaults, кроме динамических CatBoost (learning_rate/depth/l2/border_count можно явно задать). CatBoost defaults iterations150, без первоначального переопределения автоматического LR. Допустимы iterations[10,1000],depth[3,10],learning_rate(0,1],l2_leaf_reg[0,100],border_count[16,255],auto_class_weights enum None/Balanced/SqrtBalanced только classification; неверные class_weights string/sample_weight/early_stopping_rounds/thread_count/random_state отвергать с понятным советом. ExtraTrees defaults180/max_leaf128/min_leaf3/max_features.8/max_depthNone; до1000деревьев/до2048листьев, depth[2,64] илиNone, min_leaf[1,100],max_featuresfloat(0,1]/sqrt/log2/None,classification class_weightNone/balanced/balanced_subsample. Linear regression толькоdefaults; classifier C.5,max_iter300,solver saga фиксирован, C(0,100],max_iter[100,3000],class_weightNone/balanced. Thread/seed host controlled, не являются параметрами LLM.

Preprocessing только add_missing_indicators bool для ExtraTrees/Linear (CatBoost false). Индикация через SimpleImputer.add_indicator, обработка категорий/неизвестных/NaN/inf/sparse не ломается. Можно менять estimator через проверенный set_params после templatebuilder, без чтения файлов/импорта automl_agent внутри сгенерированного кода. JSON -> Python literals через repr безопасных нормализованных primitives. Fingerprint одинаков для omitted defaults и явно тех же defaults; разные параметры/веса/индикаторы различаются. Не считать пустой словарь или None нечисловых полей отсутствием валидного значения. Тесты before impl, реальные tiny fit/predict/serialization/worker для обоих tasktypes и весов.

## metadata (исполнитель, собственные worker.py и tests/test_realized_parameters.py)
Послеfit `estimator_details['parameters']` = bounded JSON dict параметров конечного реального алгоритма; `parameters_source` описывает fitted CatBoost get_all_params или sklearn constructor params. Включить iterations,learning_rate,depth,l2_leaf_reg,border_count,auto_class_weights,class_weights; ExtraTrees n_estimators,max_depth,max_leaf_nodes,min_samples_leaf,max_features,class_weight; Linear C,max_iter,solver,class_weight и thread count. Никаких y/feature values/именфайлов/rawrepr. Только exact известные native классы и безопасное чтение; не вызывать arbitrary custom get_params/getattr/repr. Metadata best-effort не ломаетfit. Старые tests/test_model_metadata.py неизменны/проходят. R4 red/green и фактический worker fixture. Не менять contracts.py/root.

## forensic (исполнитель, собственный ROOT_CAUSES.md и logs/forensic*.json)
Читать предыдущие runs через абсолютный путь основной копии; не менять runs/data/source. Проверить причины всех4 regression и8 classification LLM trials, отличие заявленного/реального, конфиги/LR, переданный context. Official primary docs по API CatBoost/sklearn. Никаких дорогих публичных fit, root проводит live. Отчёт с source links и проверяемыми доказательствами, конкретными guardrails. Read-only model params допускаются. Не просить разрешений.
