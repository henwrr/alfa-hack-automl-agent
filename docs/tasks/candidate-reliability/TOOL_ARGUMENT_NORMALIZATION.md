# Нормализация аргументов инструментов

Read-only просмотр `runs/research-cv-public-20261020/regression/events.jsonl` показал два вызова `run_model_experiments`, где `arguments.experiments` передан строкой с JSON-массивом (длина 2344 и 2401 символ). В записях решения находятся среди полей эксперимента, а не только в `decision`; старый текст `jsonschema` включал в сообщение всё значение `experiments`.

`ToolRegistry` теперь декодирует JSON-строки только в позициях, где схема требует объект или массив, с ограничением глубины 8. JSON-скаляры не преобразуются. Для `run_model_experiments` переносятся только поля, объявленные схемой `decision`; одинаковые дубликаты схлопываются, конфликтующие отклоняются. После нормализации выполняется прежняя полная schema validation, включая required, additionalProperties и лимиты массивов. Ошибки содержат путь, ожидаемый тип или ограничение и короткую причину без отображения пользовательского значения. Параметры моделей, рецепты и generated code не меняются.

В тех же сохранённых вызовах `experiments` имел ещё и лишнюю закрывающую скобку: стандартный `json.loads` завершался `Extra data` на позициях 2343 и 2400. Для schema-ожидаемых object/array добавлен ограниченный `JSONDecoder.raw_decode`: после одной полной структуры допускаются не более двух лишних `]`/`}`; текст, второй JSON value и длинные хвосты отклоняются. Содержимое декодированной структуры не меняется.

Dry-run на точной сохранённой записи: schema `run_model_experiments` взята из первого `llm_request` (seq 34), callback capture зарегистрирован без fit и вызван сохранённым tool call seq 36. `registry.execute` вернул `ok=true` и передал callback два эксперимента; у обоих decision-поля оказались внутри `decision`. Параметр второго кандидата `CatBoost auto_class_weights="Balanced"` прошёл wire/schema слой без изменений; корректность применения к regression остаётся ответственности downstream `recipes`, который здесь не запускался. Публичное обучение и live Ollama не запускались.

Проверки после исправления: `tests/test_tools.py` — 20 passed; `compileall` и `git diff --check` — успешно. Новые синтетические тесты проверяют хвост с одним/двумя закрывающими символами и отказ для второго JSON object, произвольного текста и цепочки из четырёх закрывающих символов.
