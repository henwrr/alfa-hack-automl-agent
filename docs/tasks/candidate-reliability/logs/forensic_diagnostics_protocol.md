# Протокол host-диагностики validation-классов

- Контракт: `validation_diagnostics(task, split, trial_dir)` возвращает только агрегаты `per_class` (`label`, `precision`, `recall`, `f1`, `support`), `total_classes` и `partial`. Включены объявленные классы и метки из host validation/predictions; отсутствующие классы имеют support `0`. В ответе нет значений отдельных строк, список ограничен 30 классами и упорядочен от меньшего F1 к большему. Для regression возвращается `{}`.
- Метрики вычисляет официальный `sklearn.metrics.precision_recall_fscore_support` с `average=None`, явным списком меток и `zero_division=0`. Документация подтверждает per-class режим, возможность включать отсутствующие метки (для них назначается 0 samples) и определение support как числа истинных случаев: [scikit-learn 1.5.2 API](https://scikit-learn.org/1.5/modules/generated/sklearn.metrics.precision_recall_fscore_support.html).
