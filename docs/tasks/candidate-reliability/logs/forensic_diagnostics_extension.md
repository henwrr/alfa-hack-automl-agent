- Источники API — официальная документация scikit-learn 1.5.2: [cross_val_score](https://scikit-learn.org/1.5/modules/generated/sklearn.model_selection.cross_val_score.html) описывает CV и per-fold scores; [ExtraTreesClassifier](https://scikit-learn.org/1.5/modules/generated/sklearn.ensemble.ExtraTreesClassifier.html) документирует CPU tree API и предупреждает, что impurity importance может вводить в заблуждение для high-cardinality признаков; [confusion_matrix](https://scikit-learn.org/1.5/modules/generated/sklearn.metrics.confusion_matrix.html) подтверждает явный labels order/subset и значение ячейки матрицы. Для class support и per-class metrics используется [precision_recall_fscore_support](https://scikit-learn.org/1.5/modules/generated/sklearn.metrics.precision_recall_fscore_support.html).
- Важность признака агрегируется к исходным колонкам только для allowlist известных fitted estimators и sklearn `Pipeline`/`ColumnTransformer`; OHE и `SimpleImputer` indicators складываются по source-column. Для unknown transform mapping возвращается `status=unsupported`. В ответе указано, что важность описывает модельную ассоциацию, а не причинный эффект.
