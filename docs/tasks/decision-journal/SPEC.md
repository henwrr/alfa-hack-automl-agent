# Журнал решений и исследовательская стратегия

## Цель и текущая ситуация
Пользователь хочет наблюдать решения AutoML-агента: изучение данных, выбор моделей, гипотезы, ошибки и выводы по экспериментам. Нужна реализация, а также рекомендация о CatBoost и распределении трёхчасового бюджета.

## Ответы и ограничения
CLI и существующие провайдеры сохраняются. Внутренние скрытые рассуждения не являются контрактом API: журнал содержит публичные объяснения, наблюдаемые действия и измеренные результаты. CatBoost — начальный кандидат, выбор победителя только по фиксированной host-валидации. Полный переход на нескольких исследователей в этой задаче не выполняется. Исполнители разработки: GPT-6 Luna xhigh по ранее указанному предпочтению пользователя. Коммиты только в aprelskiy_branch, push отдельно не запрошен.

## Критерии приёмки
| ID | Сценарий / вход | Ожидаемый результат |
|---|---|---|
| D1 | Новый offline или LLM запуск | agent.log и decisions.jsonl обновляются во время запуска; видны факты данных, стратегия, запуск/оценка trial, выбор и финализация |
| D2 | LLM передаёт decision вместе с кодом | Сохраняются наблюдения, обоснование, альтернативы, ожидаемый эффект, риски и оценка прошлого результата; гипотеза связана с trial_id |
| D3 | Старый вызов без decision / старое состояние | Совместимость сохраняется; отсутствие объяснения обозначается явно, содержание не выдумывается |
| D4 | Trial улучшился, ухудшился или завершился ошибкой | Host пишет проверяемую оценку с прошлой метрикой, направлением оптимизации и причиной выбора |
| D5 | Wrapper / sklearn Pipeline | Worker сообщает фактическую цепочку обученных моделей; метаданные не ломают fit/predict |
| D6 | Resume, потеря производных логов, секреты | Проекции восстанавливаются из events.jsonl без дублей; секреты редактируются; raw prompts/code не попадают в читаемый журнал |
| D7 | Разный профиль данных | Стратегия учитывает категории, пропуски, дисбаланс и доступные библиотеки; рекомендации отличаются от измеренного победителя |
| D8 | Полная проверка и ZIP | Все прежние проверки и новые тесты проходят; живой Ollama smoke подтверждает решения и артефакты; ZIP пересобран |

## Вне задачи
Изменение платформенных ограничений, гарантии победы CatBoost, новая runtime-мультиагентная архитектура, показ скрытых мыслей LLM, повтор всех трёхчасовых экспериментов.
