## Решения
Один runtime-исследователь; структурированные публичные объяснения + независимая оценка host. Стратегия — короткая диагностика, затем проверяемые эксперименты. Статические рекомендации не объявляются доказанным победителем. Отсутствующие объяснения LLM задним числом не создаются. Пропущенная host-оценка восстанавливается по измеренным результатам и помечается recovered.
