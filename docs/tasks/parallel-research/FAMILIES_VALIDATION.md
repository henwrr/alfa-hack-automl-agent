# Проверка генераторов семейств

`family_candidates` возвращает стабильный список полных `build_model(context)` кандидатов. При доступном CatBoost порядок по умолчанию: CatBoost, ExtraTrees, Linear. Если CatBoost отсутствует в профиле или окружении, он пропускается без fallback внутри этого семейства. ExtraTrees ограничен 180 деревьями и 128 листьями; числовые и редкие категориальные значения обрабатываются внутри pipeline. Linear использует разреженный one-hot с лимитом 64 категории на признак, median imputation и стандартизацию без центрирования. Классификаторы возвращают вероятности для log-loss/AUC; строковые multiclass labels сохраняются. Вес классов по умолчанию отключён.

Сгенерированный код читает seed и `n_jobs` из context. Размер моделей ограничен, случайные состояния фиксированы; CatBoost не пишет файлы и использует явное число потоков. Обе sklearn-предобработки заменяют числовые NaN/inf и безопасно обрабатывают отсутствующие и неизвестные категории.
