# Сравнение семейств, резерв refit и два параллельных trial

## Цель
Пользователь явно поручил реализовать ранее предложенную стратегию, проверить обе публичные задачи и push в aprelskiy_branch. Исходный CLI, воспроизводимость, журналы и поддержка Ollama сохраняются. Исполнители GPT-6 Luna xhigh согласно предпочтению пользователя. API организаторов пока отсутствует.

## Критерии приёмки
| ID | Вход / сценарий | Ожидаемый результат |
|---|---|---|
| P1 | Новый запуск с достаточным бюджетом | До LLM измерены до трёх разных семейств на одном host-split, есть family comparison и фактические estimator metadata |
| P2 | Две независимые гипотезы или warm-up кандидата | Два subprocess одновременно, по 4 CPU по умолчанию; сумма заявленных потоков <=8, отдельные каталоги и метрики |
| P3 | Ошибка/timeout одного процесса | Второй корректно завершается; результаты и winner публикуются только координатором |
| P4 | Новое измерение времени лучшего кандидата | Резерв refit пересчитан с масштабированием размера train, safety margin и запасом записи; изменённый deadline останавливает дальнейшие trials |
| P5 | Финализация | Используется оставшийся общий бюджет, не короткий trial-timeout; сохраняется валидный предыдущий CSV при неудаче |
| P6 | Ctrl-C / resume между началом и завершением пары | Оба процесса и потомки остановлены; неизвестные исходы не повторяются; семейства/usage/резерв и assessments восстановлены без дублей |
| P7 | Старые single-tool ответы и состояния | Совместимы; max-trials общий для baseline, семейства и LLM; warm-up не засчитывается как LLM-эксперимент |
| P8 | Оба полных публичных датасета | Live Ollama, реальное сравнение семейств, доказуемое пересечение двух процессов 4 CPU, валидные CSV/модели/логи; метрики не обязаны превысить прошлые |
| P9 | Итоговая доставка | Полные тесты, ZIP, review, короткие осмысленные коммиты, push aprelskiy_branch и проверка remote SHA |

## Ограничения
3 часа максимум на запуск, 8 CPU, 32 GB платформы; два worker по умолчанию с индивидуальным RSS cap 12000 MB (сумма cap <=28000 MB для headroom координатора). Текущий n_jobs — потоки одного trial. Локальная машина 24 GiB и Ollama, публичные validation-запуски последовательные. Новая runtime-система нескольких LLM-исследователей не создаётся.
